# pgnote — Notes Dashboard Features

## Layout

- **3-panel resizable layout**: Drag the borders between the Folder Sidebar (left), Editor (center), and Notes List (right) to resize each panel to your preference.
- **Full-height editor**: The note editor fills the entire center panel — no more tiny textarea.

## Editor Features

| Feature | Description |
|---------|-------------|
| **Copy All** | Copy the entire note content to clipboard from the editor toolbar |
| **Markdown Preview** | Toggle between raw text and rendered markdown (supports headings, bold, italic, code, lists) |
| **Word & Char Count** | Live word and character count in the editor status bar |
| **Autosave** | Notes auto-save after 5 seconds of inactivity |
| **Manual Save** | Click Save or press `Ctrl+S` |

## Note List Panel (Right Side)

| Feature | Description |
|---------|-------------|
| **Auto-Title** | First line of each note is used as its title |
| **Search** | Filter notes by content in real-time |
| **Pin Notes** | Pin important notes to the top of the list |
| **Copy** | Copy any note's content with one click |
| **Delete** | Delete notes with confirmation dialog |

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl+S` | Save current note |
| `Ctrl+N` | Create new note |

## Folder Management

- Create, select, and delete folders from the left sidebar
- Deleting a folder removes all notes inside it (with confirmation)
